If Cora Max shows more than one tank, the **Reef Room** is the first page of the dashboard — an overview of every tank at once.

## The layout

Each tank gets a tile filling an equal share of the screen. The arrangement follows the number of tanks:

| Tanks | Layout |
|---|---|
| 1 | Full screen |
| 2 | Side by side |
| 3 | Three across |
| 4 | Two by two |
| 5–6 | Three by two |
| 7+ | A scrolling grid |

## What a tile shows

Each tile summarises that tank: its name, its headline parameters, and anything currently alerting. A tank needing attention is visible from across the room without opening it.

## Moving between tanks

- **Tap a tile** to open that tank's own dashboard.
- **Swipe sideways** to move between tanks, and back to the Reef Room.
- **Tap the tank name** in the top bar to jump directly to any tank.

Each tank keeps its own dashboard layout, so the screen changes completely as you move between them. See [Editing the Cora Max dashboard](/help/max-dashboard-editing).

## Single-tank systems

With one tank paired, Cora Max opens straight onto that tank's dashboard and there is no Reef Room page.
